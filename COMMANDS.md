# Команды бота

## Пользовательские команды

/start - Запуск бота, приветствие
/menu - Возврат в главное меню
/activate <пароль> - Активация бесплатного 30-дневного периода (для старых участников)
/cancel - Отмена текущей операции
ДЕКАБРЬ - Декабрьская акция (первый платеж 499₽)
Старт - Кнопка возврата в главное меню

## Админские команды

/users - Список всех пользователей с подписками
/users_subs - Список пользователей только с активными подписками
/users_trial - Список пользователей с бесплатным периодом
/adduser - Ручное добавление подписки пользователю (по ID или username)
/db - Информация о базе данных
/cleanup - Очистка неактивных подписок
/health - Проверка здоровья бота
/stats - Статистика бота
/unsubscribe - Отписка пользователя от подписки
/broadcast - Рассылка сообщений всем пользователям
/migrate_user - Миграция пользователя на новый бот
/migrate_check - Проверка статуса миграции
/promo_add - Добавление промокода
/promo_delete - Удаление промокода
/promo - Список всех промокодов
/test_gift - Тест функции подарка подписки
/gifts_clear - Очистка таблицы подарков
